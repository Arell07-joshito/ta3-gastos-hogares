# TA3 — Gastos de los hogares en transportes y comunicaciones

Presentación web interactiva con HTML, CSS, JavaScript y Chart.js.

## Archivos
- `index.html`: contenido de la presentación.
- `styles.css`: diseño adaptable a escritorio y móvil.
- `script.js`: interacciones y cuatro gráficos.
- `datos.js`: indicadores calculados desde `SUMATORIA.csv`.

## Abrir localmente
Descomprime el ZIP y abre `index.html` en Chrome, Edge o Firefox. Se requiere internet para cargar Chart.js y las fuentes web.

## Publicar en GitHub Pages
1. Entra a https://github.com/ y crea un repositorio público, por ejemplo `ta3-gastos-hogares`.
2. Sube `index.html`, `styles.css`, `script.js` y `datos.js` a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main`, carpeta `/ (root)` y pulsa **Save**.
6. Cuando termine la publicación, la web tendrá una dirección como `https://TU-USUARIO.github.io/ta3-gastos-hogares/`.

No se ha creado/publicado el repositorio en tu cuenta desde este chat; el enlace final debe generarse al subir los archivos desde tu GitHub.
